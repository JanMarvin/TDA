# Kronecker product

TDA's `mkp`, matching base R's `kronecker(A, B)` exactly.

## Usage

``` r
tda_mkp(A, B, dir = tempfile("tda"))
```

## Arguments

- A, B:

  numeric matrices.

- dir:

  working directory.

## Value

A numeric matrix, `nrow(A)*nrow(B)` by `ncol(A)*ncol(B)`.
