# Uniform-model CDF for interval-censored data, at each observation

The same uniform-within-interval distribution function estimate as
[`tda_midf`](https://janmarvin.github.io/TDA/reference/tda_midf.md)'s
`cdf`, but evaluated at each observation's `lower[i]` rather than at
every distinct breakpoint – TDA's `midf1`.

## Usage

``` r
tda_midf1(lower, upper, dir = tempfile("tda"))
```

## Arguments

- lower, upper:

  numeric vectors, the same length, with `lower[i] != upper[i]` for
  every `i`.

- dir:

  working directory.

## Value

A numeric vector, the same length as `lower`, in the original (unsorted)
order.

## Examples

``` r
lo <- c(0, 1, 2, 3, 1)
up <- c(2, 3, 4, 5, 2)
# the estimated distribution function at each interval's own position
tda_midf1(lo, up)
#> [1] 0.0 0.1 0.5 0.7 0.1
```
