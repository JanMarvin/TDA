An R interface to 'TDA' 6.4, Goetz Rohwer's and Ulrich Poetter's program
for transition data analysis, built into the package as a library. Its
event history and transition rate models, regression, sequence, cluster,
graph and spatial methods and its matrix language are available as R
functions that take data frames and return R objects. The package keeps
the program and its methods usable and documented, and reproduces
results obtained with 'TDA'.
